# Offline evidence reports

Large generated HTML reports are intentionally not stored in Git history.

The public notebooks and compact frozen tables under `results/` contain the reproducible evidence
needed to inspect the released analyses. Canonical Phase 7, Phase 8A, and Phase 8B release SHA-256
identities are documented in `docs/reproducibility_frozen.md`.

The full v1.0.0 archival package retained by the project includes the offline HTML reports.

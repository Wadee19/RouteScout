# Scientific history

The public repository shows the clean execution path, but the project was developed through multiple frozen scientific phases. Recovery and export fixes are not part of the public execution path.

Key history that remains scientifically relevant:

- Phase 1–2: dataset/schema audit and leakage-safe target/features.
- Phase 3: simple baselines established terminal MST as a very strong ranking signal.
- Phase 4: family/duplicate-aware train/validation/test split frozen.
- Phase 5–6: learned models developed on train/validation; hybrid ranking rejected; GNN admission blocked.
- Phase 7: truth-free predictions locked before opening the held-out test.
- Phase 8A: explicit router ordering mechanism verified.
- Phase 8B: original 30-board structural frame failed the preregistered gate before routing outcomes because no easy boards qualified. A pre-outcome v4 amendment expanded only the easy structural source frame without lowering thresholds or changing the target rule. The final locked experiment used 24 valid boards.
- Phase 8B final decision: `NO_CLEAR_ROUTABILITY_BENEFIT`.
- The Phase 8B preregistration uses the generic fallback label `NO_CLEAR_ENGINEERING_BENEFIT`; the public endpoint-specific frozen result `NO_CLEAR_ROUTABILITY_BENEFIT` applies that same fallback rule to the primary routability endpoint. This is a terminology clarification, not a changed decision rule.

The detailed freeze certificates remain in the archived evidence release; this repository keeps only the clean public path and final locks.
